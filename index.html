DeepSeek Harness 远程配置服务

工程师将通过安全的远程连接，帮你把 DeepSeek Harness (DSH) 安装并配置到你的电脑上。
全程约 5~15 分钟，请按下面的 5 步操作，我们一步一步来。

①下载软件
②找到识别码
③准备你的 Key
④发给工程师
⑤等待配置完成

1下载并安装远程协助软件（向日葵）

已自动识别你的系统，点击下方按钮下载对应版本。

⬇ 下载 Windows 版 ⬇ 下载 macOS 版
  1. 运行下载好的安装包，按提示完成安装（如弹出权限请求，请选择「允许」）。
  2. 打开向日葵客户端，保持窗口打开即可。
下载遇到问题？
如果点击下载没反应，可以直接打开官网：sunlogin.oray.com/download，选择对应的 Windows / macOS 版本下载。

2找到「本机识别码」和「验证码」

打开向日葵客户端后，主界面会显示两串数字：

  1. 本机识别码：客户端主界面上方的 9~10 位数字，固定不变。
  2. 验证码：识别码旁边的 6 位数字（可能标为「验证码 / 临时验证码」），每分钟刷新。
示例 · 本机识别码
123 456 789
示例 · 验证码
123 456

💡 找不到？在向日葵主界面左上角「远程协助」/「被控端」标签页里就能看到。

3准备你自己的 DeepSeek API Key

DeepSeek Harness 运行时调用的是 DeepSeek 官方大模型 API，费用按你的账号计费。因此请使用你自己的 API Key，我们不会使用、也不会保存你的 Key。

📌 这是什么？为什么需要？

API Key 相当于你 DeepSeek 账号的「专用钥匙」，用于让 Harness 替你调用 AI 模型。
只有把它配置在你的电脑上，Harness 才能工作。费用记在你的账号上，与我们无关；我们也无法看到或使用你的 Key。

🔑 三步获取你的 Key

1

打开 DeepSeek 开放平台：platform.deepseek.com

2

登录后，在左侧菜单进入 「API Keys」 页面，点击「创建 API Key」。

3

复制生成的 sk- 开头 的字符串（关闭弹窗后就看不到了，注意先保存）。

4

把 Key 粘贴到下方输入框（可选），或稍后工程师协助时由你自己输入。

🔒 输入框已加密显示（星号）。此 Key 只会保存在你自己电脑的 DSH 配置文件中，不会上传到任何服务器。

⚠️ 重要安全说明：API Key 等于你账号的「钱包钥匙」，不要把它发给任何人（包括为你服务的工程师）——工程师也不需要知道你的 Key。 配置时由你自己在电脑上输入即可（输入过程不会显示）。如果不小心泄露，请立即到 DeepSeek 开放平台「API Keys」页面删除并重建。

把向日葵客户端里的两串数字填到下面，点击「一键复制」，粘贴发送给工程师（微信 / QQ / 电话均可）。

✅ 已复制！请把上面的内容粘贴发送给工程师，然后等待工程师连接你的电脑。

5等待工程师连接并完成配置

  1. 工程师连接后，你的屏幕上会出现「被控制」提示，请点击「允许」（第一次连接时需要）。
  2. 工程师会帮你安装 DeepSeek Harness；需要输入 API Key 时，由你自己输入，工程师不会看到。
  3. 配置完成后，工程师会告知使用方法，并在你电脑桌面创建「DeepSeek Harness」启动图标。
⏱ 预计耗时 5~15 分钟。期间电脑可以正常使用，但建议不要做重要操作；全程你可以看到工程师的一举一动，随时可以点击「断开」终止。

🛡 我们的安全承诺

  1. 你的 Key 只属于你：API Key 保存在你自己的电脑上，我们不会索要、不会保存、无法查看。
  2. 全程透明：远程连接期间，你的屏幕全程可见，可随时断开。
  3. 一次性验证码：向日葵验证码每分钟刷新、用完即失效，连接结束后自动作废。
  4. 不留后门：配置完成后，向日葵被控端可以关闭；Harness 只在本机运行。
