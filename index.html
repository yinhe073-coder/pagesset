远程协助配置服务

工程师将通过安全的远程连接，帮你把 DeepSeek Harness (DSH) 安装配置到你的电脑上。全程约 5~15 分钟，请按下面三步操作。

1下载并安装远程协助软件（向日葵）

请点击下方按钮，下载你当前系统的客户端（已自动为你识别系统）。

⬇ 下载 Windows 版 ⬇ 下载 macOS 版
  1. 运行下载好的安装包，按提示完成安装（安装过程中如弹出权限请求，请选择「允许」）。
  2. 打开向日葵客户端，保持窗口打开即可。
下载遇到问题？
如果点击下载没反应，可以直接打开官网：sunlogin.oray.com/download，选择对应的 Windows / macOS 版本下载。

2找到「本机识别码」和「验证码」

打开向日葵客户端后，主界面会显示一串号码。请对照下图找到两串数字：

  1. 本机识别码：客户端主界面上方的 9~10 位数字，固定不变。
  2. 验证码：识别码旁边的 6 位数字（可能标为「验证码 / 临时验证码」），每分钟会刷新。

💡 手机用户（客户本人）也可以直接打电话或微信把这两串数字报给工程师。

3把识别码发送给工程师

请把向日葵客户端里的两串数字填到下面，然后点击「复制」并粘贴发送给工程师（微信 / QQ / 电话均可）。

⚠️ 安全提醒：识别码和验证码等于你电脑的「临时钥匙」。请只把它发给为你服务的这位工程师，不要发给任何陌生人，验证码使用完毕后会自动失效。连接过程中你可以随时看到工程师的操作。

4等待工程师连接并完成配置

  1. 工程师连接后，你的屏幕上会出现「被控制」提示，请点击「允许」（第一次连接时需要）。
  2. 工程师会自动完成 DeepSeek Harness 的安装与配置，全程请勿关闭向日葵窗口、请勿断电。
  3. 配置完成后，工程师会告知你使用方法，并在你电脑桌面创建启动图标。

⏱ 预计耗时 5~15 分钟，期间你的电脑可以继续正常使用，但建议不要做重要操作。
